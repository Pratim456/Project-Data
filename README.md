# Studio Socially Website

A responsive static landing page for a freelance social media content planner, designer, and video editor.

## Included

- `index.html` — page structure and marketing copy
- `styles.css` — responsive visual design, cards, sections, and mobile navigation
- `script.js` — mobile menu behavior and package-to-contact interactions

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
